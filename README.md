# SmartCards

A Flutter app that generates AI-powered flashcards from a topic or a block of text, with a native Cupertino UI

## Features

- Generate flashcards from any topic
- Generate flashcards by pasting your own text
- Flip card animations with question/answer reveal
- Swipeable card deck with page navigation
- Save decks for later review
- Share decks and export flashcards as CSV

## Tech Stack

- **Flutter** - Cupertino UI, macOS/iOS/Android/Windows
- **OpenRouter** - AI flashcard generation
- **Supabase** - Secure backend and remote configuration management

## Requirements

- Flutter SDK
- macOS, iOS, Android, or Windows device

## Running the App

```bash
flutter pub get
flutter run
```
